# 학습 모듈 구조

## 전체 모듈 지도

디지터시는 하나의 숫자 코스가 아니라 `ICT`, `CT`, `AIT`, `STEM`, `VALUE`의 대영역으로 구성되는 체험 플랫폼입니다. 각 대영역 아래에는 독립적으로 개발, 교체, 확장 가능한 프로그램 모듈을 둡니다.

## ICT

ICT는 디지터시의 출발점입니다. 가장 강한 계열성을 두며, 조작의 선후관계를 모듈 내부 라운드로 설계합니다.

| 모듈 | 목적 | 현재 구현 |
| --- | --- | --- |
| 기능 조작 체험 | 마우스 이동, 클릭, 드래그, 짧은 키보드 입력을 직접 익힌다 | 15라운드 구현 |
| OS 동작 체험 | 웹 안의 가상 컴퓨터에서 앱 실행, 작업, 저장, 파일 이동을 경험한다 | 12라운드 구현 |
| 타자연습 | 한글 단어와 짧은 문장을 정확히 입력한다 | 10라운드 구현 |

## CT

CT는 컴퓨팅 사고를 문제 해결 놀이로 경험하게 합니다. 코딩 문법 설명보다 순서, 조건, 표현, 시각화가 먼저입니다.

| 모듈 | 목적 | 현재 구현 |
| --- | --- | --- |
| 코딩 퍼즐 | 장애물을 피해 목표까지 가는 code.org 수준의 캐릭터 이동 퍼즐 | 6라운드 구현, 최단 경로/부분 점수 평가 |
| 순서도에서 코드 보기 | 순서도 블록을 누르면 코드가 생성되는 과정을 관찰 | 6라운드 구현 |
| 언플러그드 컴퓨팅 시각화 놀이 | 이진수, 패턴, 논리를 조작형 놀이로 체험 | 6라운드 구현 |
| Interactive Challenge | 첨부된 인터랙티브 챌린지 콘텐츠 연결 | 연결 |

## AIT

AIT는 AI를 기술 흐름과 관점 변화로 체험합니다.

| 모듈 | 목적 | 현재 구현 |
| --- | --- | --- |
| AI 패러다임 게임 | 첨부된 AI 패러다임 게임 연결 | 연결 |
| 노드 기반 AI 흐름 실습 | 노드를 연결하며 AI 흐름과 판단 구조를 시각화 | 연결 |
| 우주 탐사대 | 코스모AI 계열 활동을 붙일 자리 | 자리 |
| AI 기술 흐름 시각화 | 추상화, 자동화, 지능화, 자율화의 흐름 체험 | 6라운드 구현 |

## STEM

STEM은 교과 융합 활동을 시뮬레이션형 체험으로 연결합니다.

| 모듈 | 목적 | 현재 구현 |
| --- | --- | --- |
| 핀테크 체험 | 돈의 흐름, 소비, 저축, 투자 균형을 조작 | 5라운드 구현 |
| AI와 함께하는 신약 개발 실험 | 효과, 안전성, 부작용 균형을 AI 예측으로 체험 | 5라운드 구현 |
| AI Studio STEM 실험실 | 가져온 AI Studio 활동을 STEM 실험 모음으로 실행 | 연결 |
| 모션 코딩 | 몸 움직임과 코딩을 연결할 자리 | 자리 |

## VALUE

VALUE는 정답형 퀴즈가 아니라 학생의 AI 가치 판단 성향을 드러내는 영역입니다.

| 모듈 | 목적 | 현재 구현 |
| --- | --- | --- |
| AI 성향 딜레마 랩 | 가져온 AI 어린이 판사 활동으로 딜레마 판단 체험 | 연결 |
| AI 가치 실습 링크 | Gemini 공유 활동으로 AI 가치 판단을 이어서 체험 | 외부 링크 |

VALUE 영역에는 다음 원칙이 어린이 언어로 드러나야 합니다.

- 사람의 생명, 마음, 몸을 먼저 지키기
- 약한 사람과 모두에게 이로운 선택 생각하기
- AI를 올바른 목적에 쓰기
- 권리와 민주적인 약속 존중하기
- 개인정보를 함부로 쓰지 않기
- 다름을 존중하고 차별하지 않기
- 사람에게 해로운 기능은 제한하기

## 모듈 설계 규칙

- 메인 플랫폼은 전체 맵, 진행률, 배지, 가이드를 담당합니다.
- 각 프로그램은 독립 렌더러나 외부 폴더로 분리합니다.
- 내부 구현, 로컬 HTML, 외부 URL은 모두 같은 미션 셸과 프로그램 프레임으로 진입합니다.
- 모듈 내부에는 반복 숙달을 위한 라운드를 둡니다.
- 일정 시간 응답이 없으면 조작 대상을 강조하고 행동 힌트를 줍니다.
- 우연한 성공을 줄이기 위해 완료 조건은 관찰 가능한 행동으로 둡니다.
