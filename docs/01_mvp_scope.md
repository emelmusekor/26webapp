# MVP 범위

## MVP 목표

첫 번째 MVP는 학생이 하나의 웹 플랫폼에서 ICT 기초, CT 기초, AIT/STEM/VALUE의 대표 체험으로 들어갈 수 있는 구조를 검증하는 것입니다.

백엔드, 로그인, 장기 데이터 저장은 전문 개발자가 이어받을 영역으로 둡니다. 프로토타입 단계에서는 복잡한 인증이나 서버 저장을 만들지 않고, 프론트엔드 중심의 모듈 구조와 로컬 진행 기록만 사용합니다.

## 성공 기준

- 학생이 플랫폼 맵에서 각 대영역과 모듈을 이해할 수 있다.
- ICT는 기능 조작, OS 동작, 타자연습으로 분리되어 있다.
- ICT 모듈은 한 번의 우연한 성공으로 끝나지 않고 반복 라운드를 가진다.
- CT는 코딩 퍼즐, 순서도, 언플러그드 시각화, 첨부 챌린지 연결을 제공한다.
- AIT, STEM, VALUE는 현재 구현/자리/외부 연결 상태가 명확하다.
- 일정 시간 응답이 없으면 가이드가 힌트를 제공한다.
- 전문 개발자가 백엔드와 운영 기능을 붙일 수 있도록 폴더 경계가 분리되어 있다.

## 1차 포함 범위

### 플랫폼

- 대영역별 모듈 맵
- 가상 컴퓨터 느낌의 바탕화면
- 미션 오버레이
- 가이드 콘솔
- 배지 보드
- 간이 교사용 진행 보기

### ICT

- 기능 조작 체험
- OS 동작 체험
- 타자연습

### CT

- 코딩 퍼즐
- 순서도에서 코드 보기
- 언플러그드 컴퓨팅 시각화 놀이
- Interactive Challenge 연결

### AIT

- AI 패러다임 게임 연결
- 노드 기반 AI 흐름 실습 연결
- 우주 탐사대 자리
- AI 기술 흐름 시각화

### STEM

- 핀테크 체험
- AI와 함께하는 신약 개발 실험
- 모션 코딩 자리

### VALUE

- AI 성향 딜레마 랩
- AI 가치 실습 링크
- 윤리 원칙 데이터
- 가치 수직선 UI

## 1차 제외 범위

- 실제 회원가입
- 실제 로그인 인증
- 서버 DB 설계와 운영
- 실제 개인정보 저장
- 실제 파일 업로드와 다운로드
- 실제 외부 인터넷 자유 탐색
- 운영용 관리자 콘솔
- 완성형 LMS 기능

## 백엔드 인수인계 경계

현재 완료 기록은 `localStorage`에 저장합니다. 운영 개발에서는 `platform/core/storage.js`를 서버 API로 바꾸고, `platform/data/catalog.js`의 모듈 메타데이터를 DB 또는 CMS 데이터로 이전할 수 있습니다.
