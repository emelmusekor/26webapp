# 초기 화면 목록

## 화면 설계 원칙

디지터시의 화면은 초등학생이 설명을 길게 읽지 않아도 행동할 수 있어야 합니다.

1. 한 화면에는 하나의 주요 행동만 둔다.
2. 버튼, 아이콘, 목표 지점은 크고 명확하게 만든다.
3. 실패 메시지는 틀렸다는 표현보다 다시 해 볼 행동을 알려준다.
4. 가이드 캐릭터는 짧게 말한다.
5. 학생이 자유롭게 눌러보되 현재 목표는 분명해야 한다.
6. 실제 컴퓨터와 비슷하지만 위험한 실제 OS 기능은 제공하지 않는다.

## 플랫폼 화면

### 1. 전체 플랫폼 맵

목적:

- ICT, CT, AIT, STEM, VALUE의 전체 모듈을 한 화면에서 보여준다.

주요 요소:

- 대영역별 모듈 카드
- 체험, 완료, 자리 상태 표시
- 선택한 모듈의 의도와 핵심 경험
- 체험 시작 버튼

### 2. 가상 컴퓨터

목적:

- 웹앱 전체가 작은 컴퓨터처럼 느껴지게 한다.

주요 요소:

- 바탕화면
- 앱 아이콘
- 작업 표시줄
- 대표 모듈 바로가기

### 3. 미션 오버레이

목적:

- 선택한 모듈을 전체 화면 체험으로 실행한다.

주요 요소:

- 현재 대영역과 모듈명
- 라운드 진행률
- 가이드 콘솔
- 따라하기 버튼
- 체험 캔버스

### 4. 배지 보드

목적:

- 완료한 모듈을 학생이 수집물처럼 확인한다.

주요 요소:

- 완료 배지
- 대영역 표시
- 완료한 모듈명

### 5. 간이 교사용 보기

목적:

- 실제 백엔드 전에도 모듈별 진행 상태를 확인한다.

주요 요소:

- 전체 진행률
- 대영역별 완료 수
- 모듈별 완료 상태

## 1차 체험 화면

### ICT 기능 조작 체험

- 마우스 목표 이동
- 별 클릭
- 드래그 앤 드롭
- 짧은 키보드 입력

### ICT OS 동작 체험

- 그림판 아이콘 더블클릭
- 캔버스 작업
- 저장
- 파일을 휴지통으로 이동

### ICT 타자연습

- 단어 입력
- 띄어쓰기 포함 표현 입력
- 짧은 문장 입력

### CT 체험

- 코딩 퍼즐
- 순서도에서 코드 보기
- 이진 전구 놀이
- Interactive Challenge 연결

### AIT, STEM, VALUE 체험

- AI 패러다임 게임 연결
- 노드 기반 AI 흐름 실습
- AI 기술 흐름 시각화
- 핀테크 시뮬레이션
- 신약 개발 실험
- AI 성향 딜레마 랩
- AI 가치 실습 링크

## 첫 프로토타입 우선순위

1. 플랫폼 맵
2. 미션 오버레이
3. ICT 반복 숙달 모듈
4. 외부 콘텐츠 연결
5. VALUE 딜레마 구조
6. 문서화와 폴더 구조 안정화
