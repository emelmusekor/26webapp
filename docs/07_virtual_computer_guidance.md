# 웹 가상 컴퓨터와 가이드 시스템

## 개념

디지터시는 실제 OS 에뮬레이터가 아닙니다. 웹 안에서 작동하는 학습용 가상 컴퓨터입니다.

학생은 웹브라우저에 접속하지만, 화면 안에서는 하나의 작은 컴퓨터를 쓰는 것처럼 느낍니다. 바탕화면, 아이콘, 창, 그림판, 메모장, 파일, 휴지통, 브라우저가 모두 이 가상 컴퓨터 안에서 작동합니다.

## 범위

구현하는 것:

- 바탕화면
- 아이콘
- 창 열기와 닫기
- 앱 실행
- 그림판과 메모장 같은 간단한 앱
- 파일 저장 시뮬레이션
- 파일 열기, 삭제, 복원 시뮬레이션
- 모의 브라우저
- 모의 게시판, 댓글, 반응, 업로드, 다운로드

구현하지 않는 것:

- 실제 운영체제 커널
- 실제 파일 시스템 접근
- 실제 외부 인터넷 자유 탐색
- 실제 프로그램 설치
- 실제 시스템 설정 변경
- 실제 개인정보가 포함된 파일 업로드

## 제품 표현

사용자에게는 `가상 컴퓨터` 또는 `디지터시 컴퓨터`라고 부릅니다.

개발 문서에서는 필요할 때 `웹 가상 컴퓨터`라고 부릅니다. `가상 OS`라는 표현은 실제 OS 에뮬레이터로 오해될 수 있으므로 핵심 문서에서는 피합니다.

## 기본 구조

웹 가상 컴퓨터는 다음 레이어로 구성합니다.

1. 데스크톱 레이어: 바탕화면, 아이콘, 작업표시줄, 시작 버튼
2. 창 레이어: 앱 창, 닫기, 최소화, 이동
3. 앱 레이어: 그림판, 메모장, 파일 탐색기, 브라우저
4. 파일 레이어: 가짜 파일, 폴더, 저장 위치, 휴지통
5. 미션 레이어: 현재 목표, 성공 조건, 힌트, 보상
6. 가이드 레이어: 무응답, 반복 실패, 잘못된 조작에 대한 안내

## 무응답 가이드 시스템

초등학생용 프로그램에서는 사용자가 멈춰 있는 상태를 실패로만 보지 않습니다. 학생이 무엇을 눌러야 할지 모르는 상태일 수 있으므로, 일정 시간 이상 반응이 없으면 단계적으로 가이드를 제공합니다.

### 감지 기준

다음 입력이 없으면 무응답으로 봅니다.

- 마우스 이동
- 클릭
- 드래그
- 키보드 입력
- 터치
- 미션 목표와 관련된 화면 변화

단순히 마우스를 조금 움직였지만 목표와 전혀 관계없는 경우에는 `헤매는 상태`로 별도 판단할 수 있습니다.

## 가이드 단계

| 상태 | 기준 예시 | 가이드 방식 | 예시 |
| --- | --- | --- | --- |
| 1단계 | 8초 무응답 | 목표물 은은하게 강조 | 클릭할 별이 살짝 빛난다 |
| 2단계 | 15초 무응답 | 짧은 말풍선 힌트 | "반짝이는 별 위로 마우스를 옮겨 봐." |
| 3단계 | 25초 무응답 | 조작 방향 시각화 | 커서 이동 경로가 점선으로 보인다 |
| 4단계 | 40초 무응답 | 따라하기 모드 제안 | "같이 해볼까?" 버튼 표시 |
| 5단계 | 반복 무응답 | 난이도 완화 | 목표물이 커지거나 움직임이 멈춘다 |

시간은 프로토타입에서 조정할 수 있습니다. 저학년 대상이면 더 짧게, 고학년 대상이면 조금 길게 둘 수 있습니다.

## 반복 실패 가이드

무응답과 반복 실패는 다릅니다. 학생이 계속 시도하고 있지만 성공하지 못하는 경우에는 더 구체적인 피드백을 줍니다.

예시:

- 더블클릭이 너무 느림: "두 번을 더 빠르게 눌러보자."
- 더블클릭을 세 번 이상 누름: "이번에는 딱 두 번만 눌러보자."
- 드래그 중 중간에 놓음: "마우스 버튼을 누른 채로 바구니까지 가야 해."
- 잘못된 곳 클릭: "이번 미션에서는 파란 별만 눌러보자."
- 주소창이 아닌 곳에 입력: "먼저 주소창 안을 한 번 눌러야 글자가 들어가."

## 가이드 원칙

1. 처음부터 정답을 대신 수행하지 않는다.
2. 학생의 행동을 평가하지 않고 다음 행동을 알려준다.
3. 텍스트만 쓰지 말고 화면 강조, 움직임, 예시 커서를 함께 쓴다.
4. 같은 힌트를 반복하지 않고 점점 더 구체화한다.
5. 충분히 헤맨 경우에는 따라하기 모드를 제공한다.
6. 따라하기 모드 이후에는 같은 조작을 다시 한 번 혼자 해 보게 한다.

## 따라하기 모드

따라하기 모드는 학생 대신 미션을 완료하는 기능이 아닙니다. 학생이 다음 행동을 보고 그대로 따라 할 수 있게 돕는 기능입니다.

예시 흐름:

1. 화면에 반투명 예시 커서가 나타난다.
2. 예시 커서가 목표 지점까지 천천히 이동한다.
3. 클릭 지점에서 원형 파동이 보인다.
4. 예시가 사라진다.
5. 학생이 같은 행동을 직접 수행한다.

## 교사용 해석

가이드가 자주 발생한 미션은 학생이 어려워한 지점으로 볼 수 있습니다.

교사용 화면에는 다음 정도만 표시해도 충분합니다.

- 완료 여부
- 재시도 횟수
- 힌트 사용 횟수
- 따라하기 모드 사용 여부

초기 프로토타입에서는 이 데이터를 서버에 저장하지 않고 화면 검증용 샘플 또는 로컬 저장으로 처리합니다.
