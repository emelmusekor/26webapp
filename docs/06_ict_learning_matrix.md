# ICT 계열성 설계

## 설계 의도

ICT는 이 플랫폼에서 가장 강한 계열성이 필요한 영역입니다. 클릭을 모르면 저장 버튼을 누르기 어렵고, 파일 개념을 모르면 업로드와 다운로드를 이해하기 어렵습니다. 다만 현재 플랫폼의 상위 구조는 숫자 단계가 아니라 `기능 조작 체험`, `OS 동작 체험`, `타자연습`의 세 모듈입니다.

각 모듈 내부에는 작은 조작 단위가 순서대로 들어갑니다. 학생에게는 게임 미션처럼 보이고, 교사에게는 선행 조작과 반복 숙달 구조가 보이게 설계합니다.

## ICT 세 모듈

| 모듈 | 핵심 경험 | 내부 계열 |
| --- | --- | --- |
| 기능 조작 체험 | 마우스와 키보드를 처음 다루는 몸의 경험 | 마우스 이동 -> 경로 따라 이동 -> 클릭 -> 두 번 클릭 -> 드래그 -> 스크롤 -> 키 역할 -> 입력 -> 수정 -> 단축키 -> 키보드 이동 -> 그림판 따라 그리기 |
| OS 동작 체험 | 웹 안의 가상 컴퓨터에서 앱과 파일을 다루는 경험 | 시작 메뉴 -> 앱 실행 -> 메모 입력 -> 저장 -> 탐색기 -> 이름 바꾸기 -> 폴더 정리 -> 휴지통 -> 그림판 실행/따라 그리기 -> 자유 조작 |
| 타자연습 | 한글을 보고 정확히 입력하고 수정하는 경험 | 단어 입력 -> 띄어쓰기 포함 입력 -> 짧은 문장 입력 -> 긴 문장 입력 |

## 반복 숙달 규칙

한 번 성공했다고 바로 모듈을 끝내지 않습니다. 우연히 맞췄을 가능성을 줄이기 위해 다음 규칙을 둡니다.

- 새 조작은 한 번에 하나만 제시합니다.
- 같은 조작을 다른 화면 맥락에서 반복합니다.
- 완료 조건은 단순 클릭이 아니라 목표 위치, 정확한 입력, 순서 실행처럼 관찰 가능한 행동으로 둡니다.
- 성공 직후에는 짧은 시각효과를 보여주고 다음 라운드로 넘어갑니다.
- 모듈 전체 완료 시에는 더 큰 클리어 효과와 배지를 지급합니다.

## 기능 조작 체험

| 라운드 | 조작 | 완료 조건 | 다음 조작으로 이어지는 이유 |
| --- | --- | --- | --- |
| 1 | 마우스 이동 | 목표 영역 10개를 순서대로 지난다 | 화면의 위치와 포인터 관계를 먼저 익힌다 |
| 2 | 경로 따라 이동 | 정해진 점선 경로의 체크포인트를 순서대로 지난다 | 조심스럽게 움직이는 조작을 익힌다 |
| 3 | 정확한 클릭 | 알림창의 확인 버튼만 누른다 | 선택과 실행의 기초가 된다 |
| 4 | 두 번 클릭 | 문서 아이콘을 두 번 눌러 연다 | 실제 OS 아이콘 실행으로 이어진다 |
| 5 | 폴더 드래그 | 파일을 폴더 안으로 놓는다 | 파일 정리의 기초가 된다 |
| 6 | 휴지통 드래그 | 임시 파일을 휴지통에 놓는다 | 삭제와 정리 개념으로 이어진다 |
| 7 | 스크롤 | 긴 목록 아래의 완료 버튼을 찾는다 | 숨은 정보 탐색을 익힌다 |
| 8 | 키 역할 브리핑 | 글자키, Shift, Tab, Ctrl, Alt, Space, Enter 역할을 확인한다 | 키 조작 오독을 줄인다 |
| 9 | 키보드 입력 | 제시어를 정확히 입력한다 | 타자 모듈로 넘어갈 준비를 한다 |
| 10 | 오타 수정 | 틀린 글자를 지우고 고친다 | 실제 입력 오류 복구를 익힌다 |
| 11 | 저장 단축키 | Ctrl 키를 누른 채 S 키를 누른다 | 앱 조작의 효율성을 경험한다 |
| 12 | 키보드 이동 | Tab과 Enter로 버튼을 선택한다 | 마우스 없이도 조작할 수 있음을 안다 |
| 13 | 한글 따라 그리기 | 그림판에서 `가`를 따라 그린다 | 마우스 제어와 글자 형태를 연결한다 |
| 14 | 숫자 따라 그리기 | 그림판에서 `3`을 따라 그린다 | 수 기호를 손 조작으로 익힌다 |
| 15 | 영어 따라 그리기 | 그림판에서 `A`를 따라 그린다 | 영어 기호를 손 조작으로 익힌다 |

## OS 동작 체험

| 라운드 | 조작 | 완료 조건 | 선행 조작 |
| --- | --- | --- | --- |
| 1 | 시작 메뉴 | 시작 버튼을 누르고 메모장을 실행한다 | 마우스 이동, 클릭 |
| 2 | 메모장 입력 | 열린 창 안에 제시 문장을 입력한다 | 키보드 입력 |
| 3 | 저장 | 저장 버튼을 눌러 파일을 만든다 | 버튼 실행, 결과 확인 |
| 4 | 파일 탐색기 | 작업 표시줄에서 탐색기를 연다 | 앱과 창 개념 |
| 5 | 이름 바꾸기 | 파일 이름을 알아보기 쉽게 바꾼다 | 텍스트 수정 |
| 6 | 파일 분류 | 문서, 사진, 임시 파일을 각각 숙제 폴더, 사진 폴더, 휴지통으로 옮긴다 | 드래그, 파일 개념, 목적별 정리 |
| 7 | 휴지통 | 임시 파일을 휴지통으로 옮긴다 | 삭제와 정리 |
| 8 | 그림판 실행 | 시작 메뉴에서 그림판을 연다 | 기본 보조프로그램 경험 |
| 9 | 한글 따라 그리기 | 그림판에서 `가`를 따라 그린다 | 마우스 제어와 글자 형태 |
| 10 | 숫자 따라 그리기 | 그림판에서 `3`을 따라 그린다 | 숫자 기호 조작 |
| 11 | 영어 따라 그리기 | 그림판에서 `A`를 따라 그린다 | 영어 기호 조작 |
| 12 | 자유 조작 | 시작 메뉴, 저장, 탐색기, 휴지통 체크리스트를 완성한다 | 앞 라운드 전체 |

## 타자연습

| 라운드 | 입력 유형 | 완료 조건 |
| --- | --- | --- |
| 1 | 짧은 단어 | `디지터시`를 정확히 입력 |
| 2 | 띄어쓰기 포함 표현 | `마우스 클릭`을 정확히 입력 |
| 3 | 짧은 문장 | `파일을 저장해요`를 정확히 입력 |
| 4 | 앱 조작 문장 | `폴더를 열어요`를 정확히 입력 |
| 5 | 긴 문장 | `천천히 정확하게 입력해요`를 정확히 입력 |
| 6 | 띄어쓰기 문장 | `띄어쓰기를 지켜요`를 정확히 입력 |
| 7 | 수정 문장 | `오타를 고쳐요`를 정확히 입력 |
| 8 | 개인화 문장 | `내 이름을 입력해요`를 정확히 입력 |
| 9 | 기록 문장 | `오늘 배운 것을 기록해요`를 정확히 입력 |
| 10 | 안전 문장 | `컴퓨터를 안전하게 사용해요`를 정확히 입력 |

## 가이드 원칙

학생이 멈추면 즉시 정답을 알려주지 않고, 먼저 조작 대상을 강조합니다. 그래도 반응이 없으면 “목표가 되는 버튼이나 입력칸을 찾아보세요”처럼 행동 단위 힌트를 제공합니다.

가이드는 다음 순서로 강해집니다.

1. 기다림: 학생의 탐색 시간을 보장합니다.
2. 대상 강조: 화면에서 조작할 곳을 표시합니다.
3. 행동 힌트: 클릭, 드래그, 입력처럼 필요한 행동을 알려줍니다.

## 확장 기준

추가 ICT 모듈을 만들 때도 상위 구조는 숫자 단계로 늘리지 않습니다. 새 프로그램은 독립 모듈로 추가하고, 모듈 내부의 라운드에서만 세부 계열성을 둡니다.
