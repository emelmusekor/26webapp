# 프로젝트 의도

## 핵심 정의

`디지터시`는 초등학생을 위한 기초 ICT 조작 역량입니다.

이 프로젝트는 학생에게 컴퓨터 개념을 먼저 설명하는 프로그램이 아닙니다. 학생이 실제로 마우스를 움직이고, 버튼을 누르고, 창을 열고, 파일을 저장하고, 브라우저에 주소를 입력하고, 댓글을 달고, 업로드와 다운로드를 해 보는 프로그램입니다.

목표는 지식 전달보다 조작 경험입니다. 학생은 안전한 가상 환경 안에서 이것저것 눌러보고, 따라하고, 실수하고, 다시 시도하면서 디지털 환경의 기본 감각을 익힙니다.

## 왜 필요한가

초등학생의 ICT 수준 차이는 큽니다. 어떤 학생은 이미 스마트폰과 태블릿에 익숙하지만, 마우스, 키보드, 파일, 폴더, 브라우저 주소창, 저장 위치 같은 기본 조작에는 익숙하지 않을 수 있습니다.

기초 ICT 조작은 코딩, AI, 에듀테크, 온라인 협업, 디지털 시민성의 출발점입니다. 그러나 많은 학습 콘텐츠는 이미 학생이 컴퓨터 사용법을 알고 있다고 가정합니다. 디지터시는 그 이전 단계를 다룹니다.

## 학습 철학

디지터시는 다음 순서를 따릅니다.

1. 보고 따라한다.
2. 직접 눌러본다.
3. 결과를 관찰한다.
4. 실수하면 즉시 고쳐본다.
5. 같은 조작을 다른 상황에서 다시 써 본다.

이 프로젝트에서 중요한 것은 정답을 빨리 맞히는 것이 아닙니다. 학생이 디지털 환경의 반응을 예측하고, 자기 손으로 조작을 통제할 수 있게 되는 것입니다.

## 제품 원칙

1. 설명보다 조작을 먼저 둔다.
2. 웹 안에서 작동하는 가상 컴퓨터 환경을 제공한다.
3. 학생이 실수해도 실제 파일이나 기기가 망가지지 않는 안전한 환경을 만든다.
4. 한 번에 하나의 작은 조작만 요구한다.
5. 성공, 실패, 재시도 피드백은 즉시 보여준다.
6. 교사는 학생별 진행 상황을 쉽게 볼 수 있어야 한다.
7. 학생 개인정보는 최소화한다.
8. 점수 경쟁보다 숙달과 반복을 우선한다.
9. 게임성은 학생이 반복 조작을 즐겁게 계속하게 만드는 핵심 장치다.
10. 이후 코딩, CT, AI, 가치 윤리 학습으로 확장할 수 있는 기반을 남긴다.

## 게임성의 위치

디지터시는 문제집을 웹으로 옮긴 서비스가 아닙니다. 학생이 가상 세계 안에서 미션을 수행하며 컴퓨터 조작을 익히는 게임형 학습 환경입니다.

다만 게임성은 학습 목표를 가리지 않아야 합니다. 보상, 캐릭터, 스테이지, 연출은 모두 학생이 마우스를 움직이고, 클릭하고, 파일을 열고, 저장하고, 웹을 사용하는 행동을 더 자주, 더 자연스럽게 하도록 설계합니다.

좋은 게임성은 다음을 만듭니다.

- 학생이 실패를 두려워하지 않는다.
- 같은 조작을 여러 번 반복해도 지루하지 않다.
- 다음 미션을 스스로 열어 보고 싶어진다.
- 교사가 설명하지 않아도 화면의 목표를 이해한다.
- 게임을 끝냈을 때 실제 ICT 조작 경험이 남는다.

## 대상 사용자

### 학생

- 초등학생
- 컴퓨터 기초 조작 경험이 부족한 학생
- 태블릿이나 스마트폰은 사용하지만 PC 조작에는 익숙하지 않은 학생
- 한글 타자, 파일 저장, 브라우저 사용을 처음 배우는 학생

### 교사

- 학급 단위로 학생을 등록하고 학습을 운영하는 교사
- 학생 개인정보를 많이 수집하지 않고도 학습 현황을 보고 싶은 교사
- 컴퓨터실, 태블릿 수업, AI/디지털 기초 수업을 운영하는 교사

## 하지 않을 것

초기 버전에서는 다음을 목표로 삼지 않습니다.

- 실제 운영체제 전체 구현
- 실제 인터넷 자유 탐색
- 고난도 코딩 교육
- AI 모델 학습이나 생성형 AI 기능 중심 서비스
- 학생 간 경쟁 중심 랭킹 서비스
- 복잡한 LMS 전체 기능
- 복잡한 회원가입, 권한, 인증 시스템

## 웹 가상 컴퓨터

디지터시는 실제 운영체제를 에뮬레이션하는 가상 OS가 아닙니다. 웹앱 안에서 바탕화면, 아이콘, 창, 앱, 파일, 브라우저를 닮은 학습용 가상 컴퓨터를 제공하는 방식입니다.

학생 입장에서는 하나의 작은 컴퓨터 세계처럼 느껴져야 합니다. 하지만 개발 관점에서는 실제 OS 기능을 구현하는 것이 아니라, ICT 조작을 배우는 데 필요한 화면과 반응만 선택적으로 구현합니다.

이 접근은 다음 장점이 있습니다.

- 실제 기기나 파일을 망가뜨릴 위험이 없다.
- 수업에서 같은 환경을 반복 제공할 수 있다.
- 학생의 실수와 재시도를 학습 경험으로 만들 수 있다.
- 단계별 미션, 보상, 힌트를 일관된 세계 안에서 제공할 수 있다.

디지터시는 먼저 아주 기초적인 ICT 조작을 안정적으로 가르치는 데 집중합니다.
