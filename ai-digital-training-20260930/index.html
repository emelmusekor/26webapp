AI와 함께 만든 결과에는 학생의 판단이 남아야 한다. AI에게 맡긴 일, 직접 고른 기준, 확인한 근거, 다른 문제에 적용한 방법을 기록한다.

FROM CHATBOT TO AGENTIC WORK

질문에 답하는 AI에서 목표를 수행하는 AI로

생성형 AI는 질문에 답하는 데서 끝나지 않는다. 파일을 읽고, 검색하고, 계산하고, 코드를 실행하고, 여러 단계를 이어서 처리한다. 사람은 목표·자료·조건·검증 기준을 정한다.

1

답변

질문에 대한 설명, 요약, 번역, 아이디어를 얻는다.

직접 할 일 질문하고 결과를 읽는다.

2

제작

문서·이미지·코드·표·활동지 등 실제 결과물을 함께 만든다.

직접 할 일 조건을 주고 반복 수정한다.

3

도구 사용

파일을 읽고, 검색하고, 계산하고, 코드를 실행해 중간 결과를 만든다.

직접 할 일 사용할 자료와 검증 기준을 정한다.

4

작업 수행

하나의 목표를 여러 단계로 나누고 중간 결과를 다음 작업에 연결한다.

직접 할 일 위임 범위와 개입 지점을 정한다.

Jev · decision model

문장 대신 선택과 확률을 돌려주는 모델

TypeSafe AI가 2026년 9월 공개한 Jev는 자유로운 문장 생성보다 분류·선택·점수화 같은 구조화된 결정에 초점을 둔다. 입력 상태를 보고 typed decision과 확률을 반환해 소프트웨어가 다음 행동을 정하도록 설계됐다.

속도·효율 수치는 TypeSafe AI가 공개한 값이다. 생성 모델과 결정 모델의 역할을 구분해서 본다.
